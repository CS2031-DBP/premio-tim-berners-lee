# Petracker: Comprehensive Pet Adoption and Health Management Platform 🐾📱

**Petracker**, the winner of the *Berners Lee Award 2024-2* for the UTEC course *Platform-Based Development* (CS2031), is a comprehensive platform designed to streamline pet adoption processes and provide advanced post-adoption health management tools. With Petracker, users can manage adoptions, schedule veterinary appointments, track health records, and receive automated notifications to ensure continuous pet welfare 🏥.

The project is developed using **Java and Spring Boot 🌱** for the backend, with **Firebase integration 🔥** for notifications and authentication, while the frontend includes both **web and mobile applications 📱**.

## Architecture and Technologies Used 🏗️

Petracker employs a robust backend architecture built with **Spring Boot** and **JPA** for data persistence. The platform integrates **Firebase** for authentication and push notifications, ensuring real-time communication with users. Security is handled through **Spring Security** with **JWT tokens** for secure API access. The system features comprehensive **asynchronous processing** using `@Async` annotations for background tasks, and thorough testing with **Mockito** for reliable functionality 🔧.
