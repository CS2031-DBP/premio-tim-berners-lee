# UniLife: Connecting University Students Across Institutions 🎓🌐

**UniLife**, the winner of the *Berners Lee Award 2025-1* for the UTEC course *Platform-Based Development* (CS2031), is a social platform designed to break down barriers between universities by allowing students to share their daily university experiences. With UniLife, students can create posts, interact through votes and comments, and explore university life across different institutions 🏫.

The project is developed using **Java 21 and Spring Boot 🌱** for the backend, featuring comprehensive functionality including user authentication, content moderation, and cloud integration with **AWS services ☁️**.

## Architecture and Technologies Used 🏗️

UniLife employs a robust backend architecture with **Spring Boot** ecosystem, including Spring Security for authentication, Spring Data JPA for database operations, and JWT for secure user sessions. The platform integrates **PostgreSQL** as the primary database and leverages **Amazon Web Services** (S3, RDS, ECR, ECS) for scalable cloud deployment. The system features comprehensive testing with **JUnit and Mockito**, asynchronous event handling, and automated CI/CD through **GitHub Actions** 🔧.
