# 👗 Thryft: Sustainable Fashion Platform

**Thryft**, the winner of the *Berners Lee Award 2025-2*, is a second-hand clothing marketplace developed for the UTEC course *Platform-Based Development* (CS2031). It allows users to sell and buy pre-owned clothes in good condition, promoting conscious consumption and sustainable fashion. Users can register, list products, leave reviews, and complete payments securely 👗♻️.

The project features a backend built with **Java 21 and Spring Boot** 🌱, with secure authentication via **JWT**, full management of products, reviews, and payments, alongside web and mobile frontends. Its standout feature is an **AI-powered virtual try-on**, where customers can upload a photo of themselves, select any garment, and instantly see how it looks on them before making a purchase 🤖👚.

> *No returns, no regrets. With Thryft, try on the clothes before you buy them.* ✨

## Architecture and Technologies Used 🏗️

Thryft employs a robust backend architecture built on the **Spring Boot** ecosystem, including Spring Security for authentication, Spring Data JPA for database operations, and JWT for secure user sessions. The platform uses **PostgreSQL** as its primary database. The system features comprehensive testing with **JUnit5 and Mockito**, asynchronous event handling via `@Async` and `@TransactionalEventListener`, and API documentation with **Postman** 🛠️.
